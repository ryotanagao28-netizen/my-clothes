# クローゼット帳

服の登録と着用記録をつけるWebアプリです。iPhoneのホーム画面に追加すると、普通のアプリと同じように全画面で使えます。

## できること

- MEN／WOMENの分類を切り替えて、部位ごとの行で服を一覧
- 部位ごとの登録数、服ごとの購入額・着用回数・1回あたりの金額・最後に着た日
- 写真、色、ブランド、サイズ、素材、購入日、シーズン、商品ページのURLの記録
- 「今日着た」ボタンで着用を記録
- バックアップの書き出しと読み込み
- オフラインでも起動

## 公開のしかた（GitHub Pages）

1. リポジトリの **Settings → Pages** を開く
2. **Build and deployment** の Source を **Deploy from a branch** にする
3. Branch を **main**、フォルダを **/ (root)** にして **Save**
4. 1〜2分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになる

## iPhoneのホーム画面に追加

1. iPhoneのSafariで公開URLを開く
2. 共有ボタン（□に↑）→「ホーム画面に追加」

## データについて

- 服の記録はiPhoneの中（ブラウザのIndexedDB）にだけ保存され、GitHubや他の人に送られることはありません。
- 機種変更やSafariのデータ削除で消えるため、「バックアップ」からときどき書き出して「ファイル」アプリやiCloud Driveに保存してください。
- 別の端末に移すときは、書き出したファイルを新しい端末の「バックアップ」から読み込みます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体 |
| `manifest.json` | ホーム画面のアイコンと名前 |
| `sw.js` | オフラインで開くためのキャッシュ |
| `icons/` | アイコン画像 |
